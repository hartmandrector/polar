## Key Domain Knowledge from Hartman
- **Bridle pin is 0.5m from container end** — not at the very end. Last 0.5m dumps all at once on pin release
- **Container opening = pin release** — separate from and after bridle stretch
- **PC drag is tension-dependent, NOT binary** — CD varies continuously (0.3 collapsed → 0.9 inflated). Positive feedback loop: more tension → more drag → more tension
- **PC stays attached throughout canopy flight** — no collapse, no removal in BASE. Bounces behind canopy with same tension-drag interplay forever
- **"Bridle stretched" isn't a discrete state** — continuous consequence of tension-drag feedback
- **No deployment bag in BASE** — canopy stowed directly in container. Same mechanics though
- **Out-of-sequence deployment is a real concern** but we can treat as sequential for now
- **Segment mass needed for acceleration computation** — ~10g per segment
