# 2026-03-08 — Deployment Frames & thetaPilot Fix

## thetaPilot Bug Fix
- **Root cause**: `atan2(pdz, pdx)` measured angle from x-axis (canopy forward), not from z-axis (hanging equilibrium)
- **Fix applied**: Changed to `-atan2(pdx, pdz)` — measures from +z (hanging down), negated so positive = backward (matching slider/rendering convention)
- Pendulum convention: thetaPilot=0 = hanging straight down, positive = aft swing
- EOM gravity torque: `tau = -mgr * sin(thetaPilot - thetaCanopy)` — equilibrium when thetaPilot = thetaCanopy
- At line stretch: thetaPilot should be negative (pilot stretched forward along tension line), pendulum restores toward 0 (hanging)
