### CloudBASE Deployment Physics Extracted
- Read `simulatordeployment.ts`, `simulatorpc.ts`, `simulatorsequencer.ts` from `new-cesium` branch
- CloudBASE has 5 deploy states: `stowed → throw → bridalextending → linesextending → extended`
- Key constants: bridle=3.29m, total line length=5.23m, PC mass=0.057kg, canopy mass=3.7kg, PC diameter=38in
- Physics: Euler integration + drag + distance constraint clamping
- Sequencer: 12-keyframe timeline with airspeed-dependent formulas — we're NOT using this pattern (physics-driven instead)
- BRIDLE-SEGMENTATION.md updated with full CloudBASE physics reference — commit `2a88847`

### DEPLOYMENT-MODULE.md Created
- Commit `4181d7a` — state handoff design for WS→CP deployment chain
- Two sub-phases: WS_DEPLOYMENT (PC toss → line stretch) and CP_DEPLOYMENT (line stretch → flying)
- Core principle: each state computes initial conditions for the NEXT state
- At line stretch, geometry determines: canopy α, pilot pendulum angle, line twist, pendulum rate
- Pilot coupling (Slegers & Costello two-body) activates at line stretch
- Deploy becomes a simulated DOF (not just a slider)
- Constraint mode auto-transitions per phase
- Camera zoom-out at deployment trigger
- Build sequence: PC rigid body → bridle segments → line stretch detection → state injection → deploy DOF → slider rendering → camera → constraint presets
