### Design Decisions
- **Legends designed for PNG export** — bubble font (bold monospace + dark text-shadow), transparent scene backgrounds, high contrast for social media scaling
- **Colors = legend cross-reference** — every value matches its corresponding 3D vector arrow color
- **Axis helpers use NED→scene mapping**: body-x(fwd)=scene+Z, body-y(right)=scene-X, body-z(down)=scene-Y
- **Canvas texture sprites** for axis labels (depthTest disabled, always visible)
- **Camera automation deferred** — manual capture first, console logs camera position on drag-end for both scenes. If repeated captures needed, add presets later. Playwright can `page.evaluate()` to set camera directly.
- **No camera keyframes yet** — only justified if wingsuit→canopy transition needs automated camera move, and only after ideal angles known from manual work
