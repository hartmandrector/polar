# 2026-03-14 — GPS Overlay + Mode Extraction Scripts

## Scripts Built
- **`scripts/gps-overlay.ts`** (commit `31be0f9`) — Overlays GPS flight data against eigenvalue trim predictions. 8 interactive Chart.js charts (V-α, V-γ, CL-α, drag polar, L/D, body rates, time series). Supports `--trim-window` for highlighting quasi-steady segments.
- **`scripts/gps-modes.ts`** (commits `0e9be72`, `ca72f41`) — Spectral mode extraction from GPS data. Welch PSD + autocorrelation envelope decay. Mode classification heuristics. Eigenvalue prediction overlay from `--polar` flag.

## Key Analysis Results (Aura 5, 2019-07-17 flight)

### Trim Overlay (gps-overlay)
- At V≈48.5 m/s (steady glide window t=30–46s):
  - α: GPS 4.5° vs model 3.2° (Δ+1.3°) — model CL_α slightly high or zero-lift α offset
  - γ: GPS -22.7° vs model -23.3° (Δ+0.7°) — excellent flight path agreement
  - θ: GPS -18.2° vs model -20.1° (Δ+1.9°)
  - q: GPS 0.1°/s — essentially steady state

### Mode Extraction (gps-modes)
- **Short period**: GPS 0.70 Hz vs model 1.95 Hz (model 2.8× too fast), ζ≈0.08 vs 0.095 (damping close)
- **Phugoid region**: 0.078 Hz in PSD (but contaminated by maneuver cadence)
- **ACF damping in q**: f=0.156 Hz, ζ=0.17 — possibly the real dominant pitch oscillation
- **ACF damping in α**: f=0.154 Hz, ζ=0.19 — confirms the q finding

### Interpretation
- **Model pitch stiffness (Mα) is too high** — short period frequency 2.8× over-predicted. Need to reduce CL_α or shift aero center aft.
- Short period damping ratio is well-matched (both ~0.09)
- The q and α autocorrelations agreeing at 0.15 Hz suggests model may be splitting one real mode into two (phugoid + short period)
- 0.078 Hz peak appears in all signals — likely maneuver cadence, not a true mode

## Technical Notes
- 5th-order polynomial detrend needed (linear detrend can't remove pullout maneuver shape)
- 5 Hz GPS rate is marginal for 2 Hz short period (Nyquist = 2.5 Hz) — higher rate data would help
- Flight data is clean pullout, good for trim validation but limited for mode extraction (no turbulence/perturbations)
- Hartman: "no such thing as hands off with a wingsuit" — always actively flying, makes mode extraction harder
