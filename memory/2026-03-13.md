## 2026-03-13 — Eigenvalue Analysis Framework

### Created: `scripts/` analysis tooling (commit `7a3fa0d`)
- `scripts/eigenvalue-analysis.ts` — main entry, speed sweep or single point
- `scripts/lib/linearize.ts` — numerical Jacobian (central differences, 9×9 excluding position), QR-algorithm eigenvalue solver (Hessenberg + Givens), mode classification helpers
- `scripts/lib/trim-finder.ts` — Newton-Raphson on (α, θ) zeroing (uDot, wDot). Parafoil-aware: accepts nonzero qDot (pendulum-stabilized moment)
- `scripts/lib/node-globals.d.ts` — minimal Node.js type stubs (no @types/node needed)
- `scripts/tsconfig.json` — standalone config, includes `scripts/**/*.ts` + `src/polar/**/*.ts` only (avoids DOM types)

### Key findings — ibexul speed sweep
- Trimmable range: ~9–17 m/s
- **Short period**: ~1 Hz, well damped (ζ=0.5–0.9)
- **Dutch roll**: ~0.16 Hz, moderate damping (ζ=0.3–0.35)
- **Spiral mode**: stable at 10 m/s, goes unstable above ~11 m/s (classic parafoil)
- **8 m/s and 18+ m/s**: outside flight envelope, trim fails
- γ ranges from -23° (10 m/s gentle glide) to -66° (16 m/s near-vertical)
- qDot nonzero at all trim points (0.7–12 rad/s²) — real parafoils stabilized by pilot pendulum

### Mode auto-naming heuristics (`nameModes()` in linearize.ts)
- Oscillatory: highest freq → Short period; lowest < 0.15 Hz → Phugoid; mid → Dutch roll
- Real: fastest stable → Roll subsidence; second → Yaw damping; unstable T₂<0.5s → Lateral divergence, slower → Spiral; σ≈0 → Heading
- Names used in terminal output, chart legends, and mode legend table
