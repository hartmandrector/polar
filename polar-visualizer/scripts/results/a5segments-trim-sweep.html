Required trim surface: qDot vs pitch throttle

Each curve = one airspeed. Dashed zero line = trim point. Negative residual at full back stick = slow-speed gap. Goal: drive all curves through zero with a smooth pitch response function.

Cubic pitch response family: f(pitchT, k)

f = −pitchT · (1 + k · pitchT²). k=0 is linear (dashed). k>0 adds authority progressively toward full back stick without changing neutral (pitchT=0) feel.

3-DOF Longitudinal Trim (uDot = wDot = qDot = 0)

Solves α, θ, and pitchThrottle simultaneously so the model holds true steady longitudinal flight at each airspeed. Pitch throttle outside [−1, +1] (highlighted) means the trim is beyond available control authority — the pendulum or pilot input would have to make up the difference in real flight.
